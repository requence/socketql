---
title: createClient
description: API reference for the createClient function.
---

Creates a Socket.IO-backed URQL client with custom exchanges. The connection is **not started automatically** — use the `SocketQLProvider` or call `connect()` manually.

## Signature

```ts
function createClient(options?: ClientOptions): SocketQLClient
```

The returned `SocketQLClient` extends URQL's `Client` with additional methods.

## Options

| Option             | Type                                  | Default         | Description                                           |
| ------------------ | ------------------------------------- | --------------- | ----------------------------------------------------- |
| `path`             | `string`                              | `'/ws/'`        | Socket.IO server path                                 |
| `transports`       | `string[]`                            | `['websocket']` | Allowed transports                                    |
| `graphqlNamespace` | `string`                              | `'graphql'`     | Socket.IO namespace to connect to                     |
| `withCredentials`  | `boolean`                             | —               | Send cookies with cross-origin requests               |
| `autoConnect`      | `boolean`                             | `false`         | Connect automatically on creation                     |
| `auth`             | `() => Record<string, any>`           | —               | Return auth data for the connection                   |
| `onConnect`        | `() => void`                          | —               | Called on successful connection                       |
| `onConnectError`   | `(error: ConnectionError) => void`    | —               | Called when the connection is rejected                |

## Client Methods

| Method           | Signature                                                        | Description                                          |
| ---------------- | ---------------------------------------------------------------- | ---------------------------------------------------- |
| `connect`        | `() => void`                                                     | Initiate the WebSocket connection                    |
| `invalidate`     | `(target: string \| DocumentNode \| Array) => void`              | Manually invalidate cached operation results         |
| `onConnect`      | `(cb: () => void) => () => void`                                 | Subscribe to successful connections. Returns unsubscribe. |
| `onConnectError` | `(cb: (error: ConnectionError) => void) => () => void`           | Subscribe to connection errors. Returns unsubscribe. |

:::note
The `onConnect` and `onConnectError` options are convenience shorthands that register listeners at creation time. The client methods allow subscribing and unsubscribing dynamically at any point.
:::

## ConnectionError

```ts
interface ConnectionError extends Error {
  data?: Record<string, any>
}
```

The `data` property contains any structured context attached by the server via `ConnectionRejectedError`'s second argument.

## invalidate

```ts
// Single query by operation name
client.invalidate('Users')

// Single query by document node
client.invalidate(UsersDocument)

// Multiple queries
client.invalidate(['Users', ProjectsDocument])
```

## waitForResult

Exported from `@requence/socketql/client`, this utility returns a promise that resolves when specific query results arrive:

```ts
import { waitForResult } from '@requence/socketql/client'

await waitForResult('Users')
await waitForResult(['Users', 'Projects'])
```
